# APS 经营指标来源

固定来源 dsh-agent-aps-plugin `4c7ffa6a53493b599627a2eb0bb2ae152460c494`。实际生成链是 ui-source/app/plugin-entry.tsx 与 scripts/build-ui.mjs；根 src/ 是历史本地数据库界面，不是当前产物的来源。原指标、固定 SQL、筛选及分析消费者迁入本目录，Agent 资源由 Manage 唯一维护，身份与受控执行归 GEA。

47 按固定17候选选择性恢复此真实生成入口。原八个纯计算和维度模块迁到 Manage `src/aps-compute`，页面从其公开导出消费。当前构建入口为 `scripts/build-aps-metrics.mjs`，默认生成受控读取页面；只有显式设置 `APS_BUILD_MODE=mock` 时才生成模拟声明与固定输入。该模式不修改源默认真实合同，实际候选模式核其 `build-inputs.json` 和声明。原50字面回归和模块运行时AST校验见 `scripts/check-aps-parity.mjs`。页面筛选使用当前公开 view-state，引用只加入当前官方会话未发送草稿；原17 model403、20表缺项及18/19真实验收仍未完成。

四个Agent新增日期发货、有值库存范围与独立仓库筛选的来源及验证，见[2026-10-20数据补充](../../docs/four-agents-data-refresh-20261020.md)。当前本地构建与正式只读取数对账不代表客户端已经安装。

同步数据的剩余字段统一维护在[缺失字段清单](../../docs/agent-missing-fields.md)，页面仅保留数值范围与必要查询错误。布局继续沿用本页原始样式，指标卡按业务窗口宽度换行，宽表格在表格区域滚动。

配置化取数按用户确认的补零规则计算：缺失数值按 0，保留其他记录的已有值；分子、分母分别汇总，不再因少量记录缺值将整个指标置空。准确率的偏差在源行补零后计算。分母合计为 0 时不计算比例；查询失败、权限拒绝和不支持的日期窗口保持不可用。公司预算不分摊至基地；基地归属为空的记录仅保留在公司合计中。该规则覆盖智能工作台和产销协同各视角的同一套计算。

销售视角复核：销售提报准确率同时校验公司汇总及完整组织分组，源数值缺失补零后统一驱动卡片、指标明细与研判摘要。明细对缺失的比较值不拼百分号或标红；查询失败单独显示“读取失败”。SQL JSON 注入前由公共 HTML 入口声明 UTF-8，避免大配置挤后编码声明导致中文来源口径与枚举乱码。
