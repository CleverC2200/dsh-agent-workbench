## 本轮行为

- ODM作为外部供应，内部实际排产量为0。明确ODM标签确定收货基地，完整调拨路径保留逐段数量。来源同时标注自产或内部承接时，列出冲突及人工处理动作。
- 页面、求解/产销存CSV和独立ODM到货CSV使用同一结果，明确“ODM默认计划到货量”及默认估算说明。实际供方名称、能力、交期和到货尚未验证。
- 内部产能负荷排除ODM需求，ODM需求单列。缺内部日产能不再单独阻断ODM；需求、库存、收货方向和硬规则的真实缺项继续保留。
- 求解CSV的原“实际主计划量”改名为“内部实际排产量”，“生产满足率”改名为“供应满足率”，并新增ODM件数、吨数和估算说明。
