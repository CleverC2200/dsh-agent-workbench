# 订单工作台指标分组接口

六指标的基地＋品项分组使用 `gea_order_kpi` 的 `view=groups`，与看板共用查询、计算和版本合同。`base` 仍按各指标合同定义筛选，不改变提货点或基地含义。

返回 `current`、`groups.rows` 和 `groups.total`。每组包含基地、品项、分子、分母、值、单位、目标、状态和已有的待判定计数；未提供的计数保持空值。原始明细的 `detailsQueryId` 与分组能力独立，不能据其为空认定品项未发布。

本期、环比、同比按看板各自时间窗分别查询，再按基地和品项对齐。缺失同期不补零，分母为零不计算率值。分组百分比不取平均；数量型指标合计分子、分母后计算。准交率的同一执行单可能包含多个品项，各组分别去重，合计重新按全部执行单去重，不能相加各组张数。

未映射品项单独保留，来源查询失败返回不可用，不能写成零或空数据。可发货天数的零日均需求组保留已知库存和零分母，天数保持不可计算；这不改变看板的计算规则。

作废率、改单率分组在原有事件筛选和数量计算之后关联唯一品项映射，保留未映射组。原有卡片汇总查询保持原调用路径；分组查询不新增另一套指标公式。

## 维度能力

`dimensions` 最多三个字段，按 `contract.grouping.supported` 选择。总监、SKU自动带基地，避免跨基地混合归属。

| 指标 | 可查询维度 |
|---|---|
| 作废率、改单率、订单满足率、准交率 | 基地、品项、品类、应责总监、SKU、客户编码、大区、省区、销售区域展示 |
| 货龄占比、可发货天数 | 基地、品项、品类、应责总监、SKU |

销售区域展示使用省区优先、大区兜底，与单独的大区或省区字段不同。满足率保留原单客户归集产品的数量集合后，关联同一集合唯一的源区域；准交率使用同一最新执行轨迹的唯一区域。归属缺失或冲突保留未映射，不修改原有指标筛选。库存与计划不具备客户或销售区域粒度，返回 `unsupported-dimension` 及具体原因，不写成指标未发布或无权限。

分组每页100项，`pagination.totalGroups` 和 `hasMore` 明示是否完整；`groups.total` 与对账来自全量，当前页不是全量排名。查询失败返回 `unavailable`，真实空集合、未映射、尚未开放原始明细与不支持某一维度分别表示。

郑州庞丽娟取基地整体的例外仅用于准交率，不用于满足率、货龄或可发货天数。该判断与看板共用代码。多个总监共同归属时，分组数量不相加，总计仍取未重复分配的原集合。
