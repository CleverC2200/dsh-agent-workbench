## 筛选修复

父页面的生产基地筛选以前会原样带入所有明细，有些视图不支持该字段，有些分仓来源的“基地”实际为分仓名称，可能返回错误或空表。

现在初始/切换/重置筛选仅继承视图支持的字段。独立分仓视图显式声明不继承生产基地筛选，表中说明其独立范围，仍可按仓库筛选；GEA用户和Consumer权限不变。
