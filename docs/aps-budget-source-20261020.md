本次只改代码、构建和验证；没有发布、安装、更新 GEA 客户端或修改源表结构。

旧业务参考使用 `doris_dw.ads_sales_prov_budget_act_monthly.BQ_XSE / YS_XSE`。本次按新表注明的客户 SKU 月度预算与未税收入取数，页面明示来源和范围；未把客户销售目标表直接当作旧财务预算的同步结果。

## 查询与显示

- 每月选择不晚于截止日的同月最新预算快照，按客户×SKU检查唯一性。重复键不任取、不重复汇总。
- 收入按实际发货日汇总到月×客户×SKU。先分别聚合，再关联；预算不会因多天发货被放大。负收入保留净退货含义。
- 按用户最新要求，数值空缺按 0 计算，保留其他记录已有值。公司指标按完整收入合计 ÷ 完整预算合计计算，不因部分记录空缺而整项留空，也不以客户 SKU 交集缩小计算范围。
- 分母合计为 0 时不计算比例。年度仍按各月达成率平均，缺少有效分母的月份不伪造比例。重复键继续诊断，不重复累加；未授权来源保持错误。
- 没有核实的基地、组织映射保持空。基地、品类、销售组织筛选后不分摊公司预算。
- 月度汇总最多12行，预算与收入分区共用一次读取。可见分页默认10行、偏移重新查询；月度汇总内部分页200的上限不改变可见列表默认值。
- 授权拒绝保留结构化错误，并停止同一查询的后续对比请求；没有更换 Consumer、数据源或正式数据库回退。
