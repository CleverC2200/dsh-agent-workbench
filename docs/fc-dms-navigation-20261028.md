## 修复

原实现暂存后不会自动跳转；免登链接位于禁止弹窗的 iframe 中。现在由 Workbench 外层通道向已授权 Host 请求免登地址并打开，保留原 iframe sandbox。HTML 不提交任意 URL，也不接收免登 token。仅 inventory-fc 允许调用，离页/身份变更后的响应不打开窗口。

回执保存完成后自动尝试打开。失败时保留已成功的订单并提示“进入DMS订单管理”重试，仅重新登录跳转，不重新下单。
