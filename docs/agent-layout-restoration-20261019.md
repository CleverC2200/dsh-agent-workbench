# 五个 Agent 页面布局恢复

本次沿用新版统一身份、GEA SQL 和每个 Agent 一份 SQL 配置；主页面参照原作者页面。默认每页 10 行，翻页重新查询。数据补接包含此前两次本地提交的分仓库存、月度费用、SKU名称、订单计划和发货批次来源。

| Agent      | 原页面结构                                      | 本次调整                                                                                                                     |
| ---------- | ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 产销协同   | 智能工作台、产销协同看板、总览/生产/销售视角    | 补充明细移到主体内容之后并默认收起；按需读取销售目标、基地产销记录、订单计划、批次流水与审批配置；缺值不带单位，数量显示为箱 |
| 基地库存   | 基地/品类/货龄/SKU结构及原指标卡                | 保留原表格与下钻；补充仓库、基地产销、订单计划放入默认收起的业务明细                                                         |
| 分仓库存   | 五张指标卡、步骤条、六个业务页签与补货字段顺序  | 恢复原指标位置和名称；最大库龄明确标注，不冒充平均货龄；长口径收起，运营观察接入基地产销记录                                 |
| 全链库存   | 五张指标卡、含渠道开关、品类/组织/库龄/订单缺口 | 保留原结构与卡片；长口径收起，订单缺口可按需查看计划与批次；基地、分仓、客户的统计范围继续分列                               |
| 经销商库存 | 客户库存/客户订单、原库存卡片及库存维度页签     | 保留原组件；恢复紧凑列表，客户分析来源未开放时保持明确不可用；现有客户库存不受影响                                           |

共用列表恢复为紧凑的标题、筛选栏、表格和分页结构。取消占据主体位置的重复说明，统计口径放入可展开入口；来源行数、更新时间等辅助字段通过显示列访问，原业务字段和顺序保留。表格首列固定，宽表横向滚动，不挤压商品名称。展开说明与显示列不触发额外业务请求。

验证：五页在1280px与560px下检查主结构、页面溢出和JavaScript错误；经销商额外验证显示列不改变查询，下一页以offset=10、page_size=10重新查询。现有PC布局与深色检查、字段顺序与数据回归继续执行。浏览器验证使用合成测试数据；真实数据和实际安装结果记录在本地交付回执，不将测试截图当作生产数据。
