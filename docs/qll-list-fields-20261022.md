# 全链库存列表补字段（2026-10-22）

本轮保持原卡片和页签、字段顺序与右侧对话区，使用现有受控GEA查询。

- 基地及品类结构：平均货龄为同基地、SKU范围内有效正库存批次的数量加权均值；关联SKU先去重，不把最大库龄当均值。大日期量来自同范围批次超60天正库存。批次快照日与日库存/目标快照分别保留。
- 经营状态依库存/目标完整性、同范围差额和大日期量判断；目标缺失保留“待核对目标”，不从部分目标推断整个组织。
- 月末预估周转按当前同范围库存和计划日均扣除本月剩余自然日需求后测算，不计未来新增入库；分母0时不生成有限天数。这是固定日均、无新增入库情景，不等于已确认月末库存。
- 分仓组织结构：批次加权平均货龄、近30日日均正向发货计算的回顾周转、超60天风险量和原风险状态。缺日期和零动销分母留空，库存及已知数量仍可统计。
- 全链内的分仓补货源与FC插件共用同一版本查询，接入未备单订单自身占用和三层缺口、精确月份计划、次月计划和月末测算。成功读取的缺失数量按0，不以月累计缺货替代当前缺口。
- 关闭“含渠道”时不读取客户库存；开启时读取客户在仓、在途和库存支撑，并展示客户明细。客户批次90–119天带不能用公司批次冒充。
- 同一轮总览只执行一次相同查询和参数的健康汇总；缓存仅在该轮存在，授权拒绝不重试，刷新重建；未使用的基地发货总览不在首屏读取。

仍缺：负责人映射、当前可调拨承诺范围、分仓目标库存对应的正式版本、客户批次数量与生产日期、带阶段/日期的完整调拨流水。计算列不替代真实业务操作和已发生数量。

直接核对与正式GEA对账涵盖基地原子分页、品类原子分页、分仓批次分页和分仓汇总，字段一致且无被拒返回字段。数字测试覆盖数量加权、SKU范围隔离、重复维表去重、缺日期和无效日历日期；加载测试覆盖关闭渠道不查客户、同轮汇总去重、刷新及权限拒绝边界。

按最新指令不等待CI，本轮仅更新本地GEA预览；不推公共频道，不执行三个插件联合启动检查。
