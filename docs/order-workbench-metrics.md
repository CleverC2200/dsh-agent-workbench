## 可判定样本展示 / Assessed samples

全量计算条件不齐时，不再清空全部已知结果。作废按逐单汇总独立样本；改单按商品明细数量保留完整有效数量分母和已判定/未知数量分子，完整率不可判定时主值保持待核；满足率只纳入需求、发货量及实际发货周期均可核验的原单产品组；准交率按执行单独立判定；缺交期或短拨映射的执行单保留未知，可判定样本与完整指标分开标注。卡片标注样本覆盖，六张表及样本环同比以“*”标识并提供悬浮覆盖说明。覆盖分母为当前查询候选记录，不声明已覆盖全部真实发货或到货订单。未知记录不补0，拒权或查询失败不发布样本。样本差不冒充全量同比环比；库存、货龄按下述最新覆盖范围计算。 / Publish independently assessed samples with explicit candidate coverage, never imputed full-population rates.

## 公式与周期 / Formulas and periods

| 指标 / Metric                    | 计算及来源 / Calculation and source                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 作废率 / Cancellation            | 按客户＋原订单号去重；接单超过12小时且进入锁定期的整单作废数，除以O接收订单数（剔除接单后12小时以内、含恰好12小时作废的订单）。按传到OMS的单据新增日期选择订单，缺失或冲突的作废时间保持未知。不能以作废数量÷下单数量替代。 / Distinct source-order counts; strictly more than 12 hours, with cancellation at exactly 12 hours excluded from both counts. Select by OMS creation date. |
| 改单率 / Amendment | 日表agents_scm_execute_detail_d，header_addtime选创建周期；逐商品明细累计数量，不按原单SKU去重计数。整单作废剔除，detailstatus=10且is_stat=1；change_order_qty、dms_last_update_qty、need_qty_origin全空剔除，其余空按0。有效量=COALESCE(dms_last_update_qty,need_qty_origin,0)，差额=ABS(COALESCE(change_order_qty,0)-有效量)。分子为custchangetime在锁点之后的差额合计，分母为有效量合计；≤7日创建+12h锁定，否则确认到货−7日。改单时间不限定同一周期；缺改量时间的非零差额保留未知，主值不以样本率代替。 |
| 订单满足率 / Shipped fulfillment | 使用履约源表 `fromorderno_month` 的统一原订单发货业务归属周期；按来源单＋客户＋商品去重，发货量按需求封顶。源表已统一订单周期，不再按商品经物流表二次推算日期。缺需求、发货量或归并冲突仍不可计算。 / Use the upstream original-order business period, distinct demand and capped shipped quantities. |
| 准交率 / On-time delivery | 按执行单号去重，客户编码仅用于关联校验；按TMS实际到货时间选周期。目的地围栏时间优先，否则到货确认时间；到货≤MAX(客户期望交期、开单确认到货、系统计算到货)+12h即准交，含边界。分母为同到货周期内剔除后的已发货执行单；全部剔除项、物理字段及缺失策略见下文2026-11-05准交口径。 |
| 周转天数 / Shippable days | 使用同日批次表工厂仓01＋工厂外租仓02现存量，与库存计划表按基地＋商品全关联，保留明细未匹配状态。全国库存与计划分别按各自完整来源汇总，不要求商品集合一一对应；现有来源记录中的空值、重复计划和负计划仍阻断计算。全国及品项日均需求=销售需求计划÷当月天数；基地日均需求=(销售需求计划＋0.5×调拨出库计划)÷当月天数。 / Factory and rented stock; nationwide/item demand excludes transfers, base demand includes half the transfers. |
| 货龄 / Stock age | 工厂仓01＋工厂外租仓02的≥60天批次库存÷同范围现存量；非零库存缺生产日期时不可计算。业务品项采用唯一product_item或pinxiang，不使用细物料组代替。 / Same factory/rented scope in numerator and denominator; retain missing-date uncertainty. |

## 缺值与完整性 / Missing inputs and completeness

缺作废时间、锁定依据、最后发货日期或完整到货/承诺交期时显示横线及具体原因。查询拒绝、字段未发布、关联冲突、零分母、源字段为空分别保留，不回退数量比率、旧 `is_ontime` 行级平均、滚动计划日均或开发数据库账号。 / Missing inputs and failed queries stay unknown; no quantity-rate, row-average or direct-database fallback.

同一来源单/产品上游多行不能证明为同一份重复数据时，保持不可计算；不得任取最大需求或重复累加已合并发货。现有快照不代表历史每日固定快照。 / Conflicting merged rows remain unavailable; current observations do not establish immutable historical snapshots.

作废指标的原订单接单周期以全部子执行记录中最早OMS新增时间归属，先归并后筛选；改单指标逐明细先按OMS新增时间筛选，不同子执行单创建时间不构成冲突。确认交期仅在确需判定锁定事件时参与完整性检查。 / Select cohorts after merging split orders by the earliest observed OMS creation time; differing child creation times are not conflicts.

小时表的OMS作废时间为空时，按客户＋原订单＋执行单＋基地从日表回补；SKU改单时间必须再精确匹配material_code。仅接受对应键下唯一非空时间，小时表已有值优先。不得用 DMS 作废时间、当前状态或加载时间替代 OMS 事件时间。 / Recover missing hourly OMS event times from unique exact daily headers without multiplying rows or overriding known hourly values.

小时表刷新期间可能暂时为空，且不覆盖全部历史。日表补齐小时表缺失的客户＋原订单＋执行单＋基地；同一执行单只要小时表存在，就保留其完整状态和商品集合，不能把日表旧的有效商品并回已作废或排除的执行单。优先级判断必须在有效状态筛选前进行。 / Recover absent execution headers from daily history; prefer the entire hourly execution before filtering status so stale daily membership cannot resurrect cancelled rows.

满足率不再依赖物流表是否保留完整历史来归属周期。源表的业务日期不是 `complete_time` 加载时间，也不再以商品各自的拆单时间代替原订单统一周期；同一原单商品的冲突数据仍保留为不可判定。 / The upstream business period is not ingestion time; incomplete trace retention does not remove otherwise valid fulfillment records.

负库存按源值纳入净合计，不补0，也不因单条负数使全国指标不可计算；净库存合计为负、缺值或重复粒度仍不发布支撑天数。 / Keep negative stock in the source net sum; one negative line does not invalidate a non-negative national total.

作废指标沿用既有历史截止规则。改单指标自本次修正起只按OMS新增时间选创建周期，读取日表当前状态及数量，不再把改单/作废日期二次当作创建周期筛选；若要求历史冻结时点，必须有相应源快照。只有最新改单时间而没有历史事件记录时，不能推断截止日前是否发生过其他改单；这类订单保留不可判定。不得为接近参考截图而剔除或拟合。 / Later events cannot be included in an earlier reporting cutoff; latest-only event timestamps do not reconstruct event history and must not be fitted to reference figures.

准交订单维度采用受控 SQL 聚合为每单一条，长度前缀按 Doris UTF-8字节编码，以避免多SKU放大订单数及大规模重复分页；解码失败拒绝该集合。 / Arrival dimensions use one governed row per order and UTF-8 byte-length tuples; invalid decoding rejects the collection.

全部页面查询继续使用现有 Consumer `order`、GEA 当前身份和原有授权。仅通过数据库开发账号验证SQL不等同页面受控查询通过。 / All page reads retain Consumer `order` and the existing GEA identity and grants.

## 维度对齐 / Dimension alignment

准交率的品项采用同一执行单、客户、原单、基地及SKU上的唯一 `product_item`；物料字典的 `material_group_name` 仅为物料组，不能替代业务品项。重复执行行先归并，品项冲突或空值保持未知；准交判定及全国去重自2026-11-05起使用执行单号。该修正升级指标计算版本，以重新读取旧报告事实并保留人工编辑。 / On-time item dimensions use the execution's unique business product item rather than material groups; cached facts are versioned independently of edits.

可发货天数目标按本次业务截图：全国（含品项及合计）<12.5天，郑州≤12.5天，其他基地<11天；总监按对应基地判定，不再使用8至12天区间。只调整目标和达标判定，不改变库存/计划计算公式。六张月周表以未舍入本期值判定满足率≤95%、准交率≤98.5%及可发货天数未达标为红色；货龄本期最高标黄，并列全部标黄，合计与缺值不参与最高比较，环同比不着色。 / Targets and current-value flags follow the supplied business screenshots.

应责总监：郑州按基地＋产品，共同负责产品分别进入两人范围；其余基地按基地，缺当月订单的库存SKU不因缺产品映射而丢失。各比较周期独立读取该月归属，不拿当前责任映射倒套上月或去年；归属冲突显示待补全，全国合计不能加总重叠责任组。 / Match responsibility by the documented base/product grain and reporting month.

2026-10-25只读回查：上述全部库存公式全国约13.44天，全仓批次≥60天占比约3.71%。这是当前历史快照计算，不声明等于参考报表的12.9/14.9天或2.2/2.3%。缺完整发货日期、承诺交期和历史事件的指标继续显示未知，不能发布已知样本率充当全量结果。 / Reconciliation follows definitions, not target-fitting.

原单关联先用原值精确匹配客户＋产品。仅允许移除客户编码后唯一的一个分隔符，且双方规范键均只对应一个原订单号，才使用格式补匹配；精确匹配有记录但缺发货日期时不挪用另一格式订单的日期。责任名单从当前周期小时表完整聚合，多人共同责任保留完整名单；名单不完整或归属冲突仍为横线。品项只接受同快照唯一库存归属或快照当月截至快照日的唯一指标归属，不用物料组推测大品项。 / Exact keys take precedence; normalization requires uniqueness on both sides and responsibility lists must be complete.

六表缺失的维度标签显示“—”，悬浮注明来源字段、缺失或冲突原因；内部未映射分组保留参与全国合计，未因隐藏标签丢弃数量。 / Unknown dimension labels remain in totals and expose their source reason on hover.

覆盖仓同时核对编码01/02与名称“工厂成品仓/工厂外租库”；编码02但名称为分仓成品仓的记录不纳入。渠道范围与计划版本作为独立对账依据记录，不因某个版本接近截图便自动切换，也不默认剔除出口、中试或无计划商品库存。 / Validate warehouse code and name; do not infer channel exclusions or switch plan sources to fit a reference rate.

## 2026-11-05 准交率最新口径

依据为本次用户文字及两张OMS截图；开头“改单率”为文字笔误，本次只修改准交率计算，不改今天已修正的SKU改单率。截图用于确认字段业务含义，未按截图数据拟合比例。

4. 分母：本到货周期内已发货且通过业务剔除的执行单数。沿已接受的发货凭据，要求装车完成时间存在；只关单而未取得发货凭据的不纳入。已有有效明细10、统计标记1及小时整抬头优先/日表补缺合同保持。缺到货事实无法归属到货周期，不宣称覆盖全部现实发货订单。
