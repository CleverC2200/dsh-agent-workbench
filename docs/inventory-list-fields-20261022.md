## 计算边界

- 日期取所选时点之前的最新批次快照；批次年龄以该快照日减生产日期计算。基地原日库存/目标比较继续沿原月份和版本策略，货龄来自独立批次快照，不把两套库存相加。可查询返回的 `stat_date` 核对批次时点。
- 只有正库存、有效且非未来生产日期参与加权及分桶。无货龄数量单独返回 `unknown_age_qty`；不把无日期批次当成0天。各桶占比以有效正库存 `age_weight_qty` 为分母；存在负库存时，不把净库存当该分母。
- 基地未来7/14日按仓库+SKU做FIFO：先消耗更老批次，再算窗口内跨入60天的剩余量，扣除当前60+的剩余量。近30日日均取快照日前30个自然日正向发货÷30，不用退货抵减；没有发货记录时数值按0。此为固定日均、无新增入库的预警情景，不是已发生库存。
- 全链7/14日是按各层阈值的期末风险存量，和基地新增超龄的含义不同；不得将两个值互换。
- FIFO截零在仓库+SKU内进行，其他仓库或其他SKU的动销不能消化本SKU风险。先聚合唯一品类再关联，防止重复维表记录扩大库存和销量。
- 所有新查询仍走配置Query ID和GEA统一通道，字段返回裁剪或授权失败继续保留结构化错误，不回退直连，不当成0。

## 加载优化和核验

- 货龄汇总由“快照+分组页+独立汇总”3个请求改为“快照+同语句分组计数页”2个请求。
- 仅显示原业务列表时不再查询未显示的独立汇总。顶部卡片仍由独立总范围汇总供数；不拿10行明细代替全量汇总。
- 分桶、FIFO、分组和分页均在服务端完成；页面只取所需分组或10行明细，不下载全部批次。原筛选、分页计数和权限校验保留。
- 同一GEA Consumer、2026-10-22快照的单轮实测：该货龄读取链7,567ms→5,841ms，最大货龄均为1,029天。只是一次链路对比，不能当作整页稳定耗时或SLA。
- 三个Agent新查询分别经正式GEA与直连对账，结果一致且无被拒返回字段。桌面1440px和窄屏390px列表检查通过，无页面级横向溢出；宽表在表内滚动。
- 数值测试覆盖分桶边界、有效数量加权、FIFO先老后新、不同仓库/SKU隔离、退货/窗口外发货、分层阈值、关联去重、筛选、原子分页；权限拒绝不重试、不补零。

定向Node测试通过、SQL测试73项通过，三个页面构建通过，固定官方SDK的 `typecheck:official` 通过。普通 `tsc` 仍报既有 `src/page-interaction/reference-message.tsx:30` 的 `user | steering` 类型约束错误；本次没有修改该文件。

本轮按已授权的 GitHub PR → CI → 合并 → 本地 GEA 更新流程交付；不进行三个插件联合启动检查。实际安装版本及产物摘要另记于本次私有交付回执。

## 分仓原列表补齐

- 补货列表备单中量、缺货量复用当前订单的11种未备单完成状态、订单自身占用及三层缺口公式；有订单而没有库存/计划的仓库SKU也进入原列表，不被左表范围丢掉。卡片当前订单不从月累计或库存占用替代。
- 按 plan_month 精确取本月、次月出货和调拨计划；缺失数量按0，计划日均按各自月份自然天数；本月剩余出货=max(本月计划−本月正向发货,0)。同月多版本冲突留空，不将其当0。
- 预计月末库存沿原式：可用库存+本月调拨计划−本月出货计划；是测算值。没有月份的计划不冒充当月已确认计划。
- 基地资源从最新批次库存按所属基地聚合可用量、有效SKU，替换旧目标库存视图里已缺失的可用库存。
- 原列映射与CSV共用 valueField，避免页面/导出读到占位字段。
