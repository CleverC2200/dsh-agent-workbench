## 仍需补全的数据

| 业务 Agent | 缺失数据 | 来源表字段及问题 |
| --- | --- | --- |
| 产销协同工作台 | 基地逐 SKU 纠偏计划的有效值 | `agents_scm_demand_sales_f.plan_qty_adjusted`，限定 `source_flag=基地口径`、`stat_month=2026-10-01`。字段和权限均存在，当前所有值为 0；需要与同表 `material_code`、`belong_name`、`act_dl_qty` 对齐后回灌。 |
| 产销协同工作台 | 若跨表补齐准确率，需可用的物料替代关系 | `agents_dim_product_list_mi.replacement_material_code` 当前全部为空；计划表与准确率表出现不同物料承接同一计划的情况，不能直接按原物料号关联计算纠偏绝对偏差。 |

这两项是数据内容与关联口径问题，不是缺列或缺权限。两张表的月初计划总数及五个基地分组总数一致，但逐 SKU 对应关系并不完全一致。基地准确率表还有重复月份、基地、物料组合，因此不把另一张表的计划逐行回填，避免重复计算。

补充来源仅支持公司／基地单月达成率；品类、品项、SKU 和销售组织维度没有可核实的同口径计划时不分摊。原准确率表有有效纠偏计划时仍优先使用原表。权限错误、查询失败、计划字段未返回、基地初始计划不一致、分母为 0 时均不使用补充结果。月初阶段观察值不代替两阶段综合准确率，不参加综合准确率健康判断。
