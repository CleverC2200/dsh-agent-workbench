# 预警指标固定采用 V0.6

预警页面和执行器统一内置核心指标问数 V0.6 的 161 条登记记录。工作簿实际页签仍为“核心指标问数V0.3”，来源记录保留原页签、行号与文件摘要。每条定义、公式、排除条件、单位、时间范围和风险规则按原登记导入；未维护阈值不自行补值。

同名指标采用固定默认行，其他业务模块的同名项在指标名称中带模块后缀。“当前库存”对应原登记第 42 行，“当前库存（基地库存）”对应第 157 行；旧任务名称保持可读，不再因合法的跨模块同名而显示待核实。页面与执行器从相同随包资源读取，不依赖个人 Excel、个人配置或联网查询定义。

真实 Host 和页面入口的构建验证确认全部记录进入产物；两个独立空白浏览器在断网时逐项读取 161 项，显示文本一致。合并主线后 70 项定向回归通过，覆盖指标、人员、执行归属、白名单及已合入的取消数量修复。

本次不改业务 SQL、数据库结构或同步任务。另一工作树的数据结构接入保持独立；正式发行与客户端验收结果在发布回执中记录。
