# 预警负责人匹配与合并推送

已发布 Workbench 0.1.128，配套 GEA 0.0.307 和已发布 Manage company.81。合入预警分支 71bb6544，负责人支持品类、基地及交叉范围；组合专属优先，否则合并品类与基地负责人，同一身份去重。历史任务保留指定接收人，新任务可选择自动匹配。

同一任务、同一检测轮次、同一用户仅发送一条汇总。40项异常只调用一次发送，完整明细保留在执行记录；较长消息只收敛摘要，不分裂成多条。批次先持久化后发送，共享幂等标识与回执，未知结果不自动重发。配置沿用认证白名单，身份沿用统一飞书服务，不携带个人密钥。

源码 #361、配套 Host #439 与 #440 已合入主线。保留主线月计划导出、默认昨日、手动日期、预算进度、固定指标、人员搜索、DMS 及库存取数。81项预警回归、6项Host存储回归、7项预警浏览器回归、131项关联页面/质量回归及121项影响计划回归通过；构建与当前功能PR门禁通过。未发现历史能力删除或修复回退。

本次发行仅升版与补充兼容声明，实际打包、来源下载和正式客户端验收后回填；测试使用模拟收件人，尚未向真实员工发送消息。发布技能 1.3.0 为经确认的本机 local_draft，维护源未登记，不改动同事工作树、Core或数据结构。
