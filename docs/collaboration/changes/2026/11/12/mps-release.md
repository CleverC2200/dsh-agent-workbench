# MPS 修复与提速发行

MPS 自动准备发货和库存输入；缺项按来源、字段和处理动作输出。SQL 批量读取由200行扩大至5000行，保留完整性、权限及总量校验，等待所有在途输入完成后再评估。既有金额核对、ODM 到货和需求推导改动一并纳入。

- 对比基线：`05f4c43e46ded72e5e8f94211c0f5c49932f8375`，目标版本 `0.1.93`。
