# 产销协同预警客户端合并

合入 `codex/alert-module-20261106` 的检测任务管理、预警生命周期、执行记录、卡片/列表与详情视图，包括操作列对齐及跨逗号空值规则修复。当前主线已有页面、风险提示与数字人入口保留；正式数据页不混入模拟行动建议。后台不可用时延续原看板风险提示，轮询不重叠，失败后降低重试频率。

- 对比基线：Workbench `2c2115b38a258c645844b7b3dd5f01a46df7b87c`；计划版本 `0.1.96`，包含主线销售计划 `0.1.95` 的修复。
- 历史修复审查：保留主线最近的指标判定、默认最新日期、手动选日、页面恢复、库存来源及 MPS 变更。没有删除文件；恢复了分支原来移除的闭环标准和数字人状态入口。
- 定向验证：同事22项预警生命周期、规则、通知队列与归属回归通过；增加未配置后台不会创建原型目录或启动服务的测试；桌面和窄屏预警筛选、任务操作列、执行记录交互通过。既有APS与Frame浏览器回归单独记录。
- 主线兼容回归：更新面板浏览器用例改用当前原生重启接管协议，覆盖单次请求、失败重试、面板关闭后的进度、未知客户端版本与窄屏；不恢复旧版插件自行安装流程。
- 按用户范围：本轮不部署 PostgreSQL/XXL-JOB，不验证真实定时检测或飞书送达。后台通过显式 `GEA_WARNING_HOME` 接入，未配置时返回不可用；不再自动使用同事Windows目录与默认调度凭据。
- 发布技能：本机 dsh-plugin-release 1.3.0，local_draft；源码、频道和GitHub发行证据由本轮发布后记录补充。
