# 产销协同预警执行和回执修复

Workbench 0.1.148 候选基于正式版 0.1.147。

- 已启用的定时任务可以立即执行一轮，任务继续按原定时计划运行。编辑保存沿用原任务和启停状态，页面显示保存回执并在失败时保留表单。
- 规则校验保留逐字引用要求，识别系统自身追加的空值说明。最终回复可读取单个完整 JSON 代码块，仍以实际检测结果通过完整性校验为准。
- 失败回执发生并发冲突时基于最新版本补写，保留已确认回执。超时仍缺回执的记录显示待核实。历史记录不自动重跑。
- 71 项预警相关回归和 10 项浏览器回归通过。覆盖调度、检测规则、负责人和消息汇总。缺日均计划需求时仍保留完整性校验。

关联 [负责人沙箱保存](../17/warning-owner-sandbox-save.md)。本轮无功能删除，既有通知配置归属与规则定义继续沿用。
