# 库存卡片与列表一致性、单仓加载优化

全链品类与组织列表原来读取旧货龄汇总的库存数量，而卡片已读取当前仓库总量。列表现改为以同批次默认 SKU 汇总的数量和动销驱动，货龄仍关联原货龄字段，保留无货龄的当前 SKU。

默认 7 天补货周期、3 天准备期的汇总直接读取预计算字段；自定义周期、规则和导入计划继续使用动态计算。新增路线复用已有筛选、覆盖及有效分母口径。

验证：当前账户受控网关 174 项对账通过，覆盖三工作台卡片与列表、三个单仓、全部/需补货/有业务筛选及新旧汇总 44 个字段。SQL 回归与默认/自定义路由测试通过；同场景汇总查询约从 6.6–6.7 秒降至 1.5–1.6 秒。速度为一次环境采样，不作为服务保证。

历史修复审查：保留指定货龄段数量、严格空值、仓库排除规则、原权限及自定义周期计算；无文件或能力删除。发布前阶段：已验证待发布。目标 Workbench 0.1.91；配套 GEA 仅增加明确版本兼容，Manage 复用已发布版本。客户端安装验收另行记录。
