# 库存每日汇总与首屏查询合并

全链、基地和分仓默认看板读取已发布的三张每日汇总表，首屏静态配置查询合并，减少重复快照读取及明细聚合。自定义日期、筛选和补货周期保留对应原口径；经销商数据口径不变，按含渠道选项读取。

整合另一个库存加载任务 dd785c4 的共享调度、辅助指标、货龄校验、ASN/FIFO 和洞察接线，并合入主线 6380770 的基地库存范围提示、订单/MPS 修复和更新入口修复。发布检查期间主线合入 #204 的订单处理卡片和短缺编辑窗口；已随 f03bd4d 一并整合，并补跑对应回归。

用户明确要求移除大块“部分数据暂不可用”提示；缺失数据仍显示“-”，结构化错误、取消和权限拒绝诊断保留。卡片与 SKU 列表的目标冲突处理各沿用原口径；分仓 ASN 只含基地发货仓，空单头数量按零，基地客户订单保持原逻辑。没有删除文件或公共接口。

本轮修复的是重复在线明细计算、串行查询和整组库存聚合被单页截断；汇总与明细对账、权限拒绝、分页完整性、筛选及排序均有回归。旧缺货测试夹具增加批次发现和原子分页响应，原业务断言保留。

合并前证据：48 项数据库对账、60 条改造查询对账、63 条真实 GEA 查询及三条首屏合并查询通过；30 次受控页面性能对照无数据差异。合并后静态质量检查、汇总路由/查询合并回归通过，正式 CI 和最终交付证据在 PR/发行回执记录。测试不证明 AI 洞察时延或用户 Native 升级。

发布技能 dsh-plugin-release 1.2.0 来源为 local_draft；本任务没有同步 Skill 到团队。版本计划 Workbench 0.1.50、Manage 0.6.3-company.46、GEA 0.0.215。此页记录候选状态，频道及 GitHub Release 尚未发布。

## 合并回归补记

历史明细查询测试显式使用未启用每日汇总的配置，继续保护原筛选、权限、取消、分页与日期行为；新增每日汇总测试独立保护批次路由与返回权限，真实 GEA 页面测试覆盖当前完整配置。测试中的 ASN 执行表、仓库字段和集合分页元数据同步到现行合同，没有放宽生产校验。

全链 SQL 生成器现在识别集合分页外层，重新生成源公式后恢复分页外层及原汇总路由。回归同时比较重建前后的实际查询结果、完整分页元数据和二次生成幂等性。基础订单生成器的测试将两种等价非空谓词统一后比较语法树。订单完整性失败测试核对新一轮必定重试，避免把并发请求恰好重叠一次当作业务合同。

冷 runner 首轮完整 CI 发现 ASN 独立用例误调用系统 Python，现复用锁定 requirements 的 uv 环境，并在影响分析中声明此测试的 Python 工具需求。旧浏览器用例显式返回空汇总批次及真实目录总数，权限失败用例保留横线与日志断言，改为等待请求发出后核次数；APS 页签用例等待加载完成并从滚动容器顶部操作。修复后相关 108 项中的失败项及源码检查 25 项、页签稳定性检查均通过。最终 CI 结果随发行回执记录。

第二轮远端回归已通过前述 SQL 与浏览器修复，另发现测试把固定次数的 setImmediate 当成调度完成、以及表格旧行仍可见时提前断言新请求参数。改为有时限等待真实通道/请求状态，身份撤销、取消消息和服务器筛选断言不变；定向 13 项通过，通道测试连续 5 次通过。
