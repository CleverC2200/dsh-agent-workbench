# 库存工作台一致性与数据补全

本轮发布整合此前库存 V3 订单口径、汇总取数优化与卡片/列表修正，并补充以下内容：

- 补货卡片、列表、建议、确认清单及日期入口要求已校验汇总；未就绪或不覆盖范围时不替换成实时明细。同一页面在北京时间自然日内共用批次，显式刷新和跨日重新选批次；每个读取器固定刷新代次。
- 客户库存按已发布字段补充大日期库存，缺少品类时使用同 SKU 唯一主数据分类；冲突记录保留未知，正常记录独立汇总。
- 渠道日期共用一次读取；补齐分仓列表仓库名称/编码、货龄风险排序和下游客户表述。缺失或失败的洞察显示简短占位。

未新增汇总表，未更改每日同步 SQL；基础订单、渠道在仓及已发货订单池口径按已确认规则保留。不同数据权限或计划输入可能产生不同结果，不能把同一天等同于同批次。未捕获历史重新进入跳值的触发过程，本轮通过约束来源与批次防止混算，不宣称已证明历史根因。

验证：102 项定向回归通过；候选构建、类型检查及修改文件 lint/format 通过。真实授权会话重复进入结果稳定，同批次卡片与正补货清单合计一致。真实重复验证使用一个账号的独立会话，跨用户隔离由自动化测试覆盖。正式发布前继续整合主线并核 CI、归档、频道和来源下载。
