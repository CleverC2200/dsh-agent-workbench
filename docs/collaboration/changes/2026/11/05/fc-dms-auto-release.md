# 分仓收货信息自动关联与库存展示更新

本次 Workbench 0.1.65 包含货龄结构产品标签与紧凑展示、补货确认与列表排序一致、确认弹窗精简列及主列表库存和订单字段前置。确认收货信息改为自动带入，三个业务编码只读；存在多个有效地址时选择地址名称，编码随之联动。未读取成功或关联不完整时不能暂存 DMS，Excel 导出及补货数量草稿保持可用。

GEA 配套 0.0.234 从已授权分仓汇总读取收货信息，避免依赖当前账号无法读取的客户主数据。每日汇总 V13 在原分仓表中增加四个业务字段及收货信息口径，按最新执行单的收货仓关联客户，没有执行关联时使用唯一同名客户；地址完整保留供选择，提货点编码与名称成对核对。仓库及基地权限维度保持原规则，库存和订单计算口径不变。

验证包含受限账号真实读取、单地址自动带入、多地址选择、只读编码、切仓清空、迟到身份结果丢弃、零量不读主数据，以及原库存筛选、合计与人工计划行为。实际 DMS 暂存仍由业务人员复核后操作，本轮验证不创建业务订单。
