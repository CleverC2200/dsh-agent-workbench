# 库存筛选及当前调拨取数修复

对比基准：Workbench 0.1.63（0332902f）。本轮目标版本0.1.64。

- 表头筛选的“应用”原来依赖原生表单提交，在客户端受限容器内不会触发。改为按钮和回车直接应用，保留数字区间校验、清除和焦点恢复。回归在相同容器限制下核对下拉、文本、数值筛选及列表、分页、合计。
- 货龄筛选改为汇总前筛选批次。每行库存、可用量、加权货龄、最大货龄和底部全结果合计均使用所选范围；未勾选时仍为全量。原分仓汇总表补三种货龄范围，无需新增表、字段或权限。同步脚本 V12 通过 56 项对账后启用，配合本版上线。卡片继续使用全仓口径，90天及以上列表库存合计应与滞库风险量一致，两段全选应与超龄库存量一致。
- 当前调拨在途、备单按用户确认的本月分仓登记件数统计。历史执行单不再充当当前调拨状态。重复一致值取一次，冲突、负值和缺失按字段隔离，正常记录继续汇总。客户订单与满足率口径保持不变。
- 全链品类周转合并同范围基地与分仓库存、实际动销后重算；目标周转继续保留计划口径。渠道库存排除单条无效负库存，正常数据继续统计。修正基地SKU下钻的汇总路径选择及分仓动销时间窗口，简化首屏计数表达式。

历史行为审查：移除执行单推算当前备单/在途是用户明确确认的业务口径调整，原供货调拨订单明细与客户订单能力保留。旧入口脚本保留并转发新实现；对应旧假设测试替换为本月字段、单位、去重、异常隔离及历史执行单不干扰的行为测试。未新增仓库排除、权限配置、表或视图。

验证：SQL执行回归、单位与仓库范围回归、受限容器筛选与全链品类测试，以及实际受控网关、每日汇总逐字段对账。业务实例、账号凭据和私有回执留在任务载体，不进入公开记录。正式频道、安装及版本验收由本轮发布回执分别记录。
