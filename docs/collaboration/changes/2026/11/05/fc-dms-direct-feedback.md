# DMS暂存直接执行并显示提交反馈

用户反馈点击暂存没有明显反应。实际失败发生在DMS发送之前，原预检要求尚未配置的GEA确认快照/回执业务写库，错误文字又位于长弹窗的滚动内容中。按用户明确要求“暂存dms不应该过gea”，新DMS预检成功后直接调用专用DMS操作，使用Host已有的持久意图、批次、unknown及回执保护，不新增GEA表或写授权。

核对及暂存进度显示在固定操作区，失败提示跟随按钮可见，处理中按钮禁用并显示状态。旧Host返回local-configuration时保留旧留档兼容和既有回归，原挂起回执不丢弃。本轮不发送真实业务测试订单；真实账号只读预检、直接分支无GEA持久化和失败/回执呈现已覆盖。

分仓计划导入后的补货重算读取中，重复嵌套的下游订单CTE使旧明细查询在网关解析阶段失败。将五条相关查询整理为同层CTE并复用完全一致的定义，保留参数、字段、权限、排序和数量公式。五条真实网关查询通过；修改前后源数据对账一致。计划校验与重算样例、页面导入回归及补货SQL覆盖通过。用户原始Excel尚未直接验收，记录为现场复测边界。

配套组合为 Workbench 0.1.67、GEA 0.0.237、Manage 0.6.3-company.53。合并发布前刷新主线并保留主线已有的订单工作台范围提示。基地周转口径本轮只核对，不调整指标。
