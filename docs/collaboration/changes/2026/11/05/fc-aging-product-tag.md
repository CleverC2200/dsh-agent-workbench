# 分仓货龄结构产品标签与紧凑展示

货龄结构在风险状态后增加“产品标签”，按商品编码读取商品产销资料的 tag 原值；未设置时显示 `-`。查询只关联当前页商品，并先合并一致重复标签，库存筛选、分页及全范围合计保持原口径。原三张汇总表及 V12 同步脚本不变。标签字段未获返回权限不会阻断已授权库存列表，不更改权限配置。

仅对分仓货龄结构缩小默认列宽、行高和筛选区留白，保留列宽拖动、排序、列设置、筛选、合计及横向滚动；长文本可悬浮查看。其他列表保持原样。

验证包含重复/空/冲突标签、标签返回权限裁剪、明细与汇总路径一致、货龄范围合计及受限页面中的筛选和列宽操作。当前账号受控网关已读取到标签，库存、货龄和合计保持一致。此变更尚未发布。
