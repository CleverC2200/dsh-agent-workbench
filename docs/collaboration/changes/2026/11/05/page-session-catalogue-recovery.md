# 页面刷新后的会话目录恢复

复测基地缺货排行发行输入时，消息页刷新会因 `sessions.retain: unknown session` 崩溃。页面记忆恢复得早于 Core 实际会话目录，常驻 Document 在目录就绪前直接借用了保存的地址。

现在只有 Core 当前目录确实包含该会话时才把编号交给常驻呈现。目录准备期间保留页面、保存的关联和原 DOM；目录到达后借用同一个 Core Session。缺失会话仍走原恢复错误，不新建、不删除或改写历史，不改变身份和业务权限。

验证：真实源码 Profile 的刷新回归复现原错误；company-ui 新增目录延迟回归修复前失败，修复后完整 69 项通过。正式发行仍需本次固定组合的完整 CI 与接收证据。

首次 hosted 检查在 SDK 准备前因 runner 可用空间仅 13.28 GB、低于现有 30.06 GB 准入要求而拒绝，尚未执行产品测试。沿用 GEA 已有的临时 Linux runner SDK 清理步骤，清理本任务不用的镜像预装工具，不降低空间准入或略过 SDK/测试；不在开发者本机执行。
