# 分仓列表列宽调整与当前订单批量明细导出

分仓配置列表启用已有拖动列宽组件；当前客户订单及展开的产品明细也支持列宽拖动和键盘调整。

订单前增加勾选框，支持本页全选、全选筛选结果、跨页保留选择及取消个别订单。提供导出已选明细、导出全部明细两种 Excel 操作，不需逐条展开订单。导出沿用当前账号、筛选范围下的原受控订单与产品明细查询，按分页读取完整集合并核对订单、SKU数量及数量合计；错误、拒权或数据变化不下载部分文件。身份、筛选、分仓或刷新变更取消导出并清空选择。

没有改动SQL、字段映射、业务公式或权限；仅配置既有列宽开关。覆盖多订单、多SKU、跨页订单与超过一页的SKU明细、选取排除、数量对账、拒权及取消的测试，包含实际 Excel 下载内容校验及桌面/窄屏交互。正式候选尚未发布安装。
