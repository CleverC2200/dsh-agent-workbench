# 销售计划分摊取整并展示DMS失败原因

组织汇总数量按各计划原确认量比例分摊后，每份独立四舍五入为整数，允许合计存在取整差额。DMS明确返回不可重试的业务失败时，前台展示经过过滤的原因和错误编号，记为失败；断网或未知结果继续保留原请求核对。黄色提醒明确说明提交结果尚未确认，提供查看和核对入口。

本次仅发布客户端修复。退回携带数量调整及其服务端改造按用户要求暂缓，管理端和Java业务后端不变。

验证：24项模型与48项浏览器检查通过，定向类型检查无诊断。真实计划本地预览中，合计9、12、800件分别分配为4/5、5/7、283/517件，未提交生产审批；验证草稿已清除。历史小数不会被自动改写，真实DMS归档写入尚未验收。
