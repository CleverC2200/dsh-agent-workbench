# 分仓跨日按完整汇总批次业务日期计算

原当前工作台直接使用上海日历日期。新的一天尚无可用汇总时，库存卡片仍能读取旧批次，但补货分母、备单/在途和明细参数越过批次范围，被 SUMMARY_SCOPE_NOT_COVERED 拒读，页面整块显示缺失。

分仓当前工作台改为在加载业务页前复用已有的授权汇总元数据读取，取完整批次业务日期，统一卡片、列表、人工计划试算、周期及补货确认的计算日期。旧批次可继续按其日期展示，旧批次时只增加简短汇总日期；新批次在刷新后统一切换。身份变化清除旧页，拒权和异常日期不回退明细，不放松原汇总范围校验；不改变历史查询、其他Agent、权限、SQL或取数公式。

真实账号下先复现范围拒读，再按既有V13同步流程完成逐字段对账并启用新数据。实际客户端已确认卡片和列表恢复、补货合计一致。代码覆盖跨日重复进入、刷新推进新批次、拒权和取消；库存及批次相关87项定向检查和45项质量检查通过。客户端修复尚未发布。
