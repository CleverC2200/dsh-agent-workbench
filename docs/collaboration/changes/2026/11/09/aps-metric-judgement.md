# 产销协同指标判断与真实数据适配

真实数据分支将达成结果显示为“已更新”或“目标待接入”，并强制显示“未判定”，因此已有数值和目标仍不评价。生产和销售视角改为共用 Manage 的指标分类入口，覆盖卡片、品类→品项→物料组、基地/销售组织下钻及风险清单。无值保持无数据，无目标的库存数量保持观察项；组织综合风险按已知指标的风险等级判断，不比较不同目标的百分比大小。

订单满足率 >95%健康，90%至95%预警，<90%严重；缺货量沿用原型零目标、正数预警、超过3显示单位严重的规则。保留现有已配置的预测准确率80/75、生产计划99/95、可发货天数8–12天开区间，以及销售预算95/90、销售准确率70/65规则，没有回退旧原型的演示参数。未更改数量公式和单位。

实际数据库元数据确认 `agents_scm_demand_sales_f` 的基地字段是 `belong_base`，没有旧字段 `belong_name`。24处准确率明细、汇总、选项、分页、页面与下钻查询全部适配，并用真实字段的本地样本执行汇总及筛选回归；当前账号 GEA 查询已通过，不再报旧字段未发布。

`agents_sales_plan_demand_m` 已有且 GEA 可返回产品大类、物料组、大区、省区、销售组。原计划查询硬编码空值，现从原客户×SKU×基地粒度传递实际分类，首屏只按基地/大类汇总，品项和组织按需读取；分页计数、排序和完整性键同步扩展。未关联额外事实表，重复冲突行仍不任选维度或数量，未知分类保留在完整总量中。当前账号真实对账确认：页面、汇总、产品、组织四路径计划总量一致，基地销售计划量也与修改前保持一致。私有业务明细不写入共享记录。

当前账号可读范围内，本月准确率记录只有基地口径，滚动计划数量为0；销售口径未返回记录。分母为0或记录不可用的准确率仍无法计算，不用月初计划替换滚动版本。公司预算没有组织归属、客户计划执行等尚无等价口径的缺口仍保留，不按比例补造。

验证包括真实页面组件的生产/销售判定浏览器测试、阈值边界/无值/无目标测试、准确率字段样本、计划维度与重复冲突样本、真实 GEA 四路径对账和局部构建。完整作者源类型检查仍有15项既有错误，本次无新增。未调整权限、任务或业务订单写入；未修改正式客户端，未发布。
