# 预警接收人与指标口径、DMS 暂存修复

预警接收人不再依赖每台电脑的个人脚本和映射文件，改由已有预警执行器使用指定飞书应用校验 GEA 工号。应用凭据仅保存在服务器私有配置；查询不发送通知，发送继续核对任务归属并保留未知结果防重。

指标口径随版本提供，来源为产销协同指标登记表 revision 1445，包含 161 条登记记录。同名冲突保留待核对，唯一别名可匹配。分仓库存差额显示分仓×SKU 的有符号净差额、目标缺失/零值及 A540 排除规则；该条登记的健康/预警/严重阈值未维护，不自行补阈值。检测提示词使用与页面相同的公式、排除规则和来源。

同组 DMS 修复允许证明尚未发送的失败重试，未知结果不重发，成功回读原回执；页面显示 DMS 返回的业务说明和订单号。

本次不修改业务 SQL、汇总脚本、数据结构或调度取数任务。新数据结构接入保持在另一工作树，未合入本次候选。

本地验证覆盖人员工号、状态、分页、通知回执防重、指标来源与页面显示，以及 DMS 暂存相关回归。指定飞书应用已完成只读身份核对，未发送真实通知，也未新增真实 DMS 订单。

部署、正式发布及客户端验收尚待完成。当前 GEA 登录账号在受控 APS 授权检查中被拒绝，权限未修改；正式客户端验收需要有 APS 权限的登录身份。服务器更新须使用独立连接，保留其他对话正在使用的终端。
