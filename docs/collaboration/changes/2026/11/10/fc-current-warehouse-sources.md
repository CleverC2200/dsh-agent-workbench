# 分仓库存最新来源

用户确认两张新来源修正字段错位后以最新内容为准。本次将分仓当前库存、可用、占用、冻结、调拨备单和在途统一到仓库总量来源，将客户订单需求、占用和发货统一到执行明细的件数口径。执行明细不再重复除单位换算率，按组织、货主、执行单、行号识别唯一行；一致重复行去重、冲突行隔离。卡片、补货列表及 V18 汇总使用同一查询定义。

月度计划、货龄批次和动销使用原来源；不根据不同来源的总量差额推算货龄批次。仓库权限字段、分仓分类、仓库排除、客户订单状态和月度已发货订单池满足率公式保持原有规则。零值按新来源保留，未知不回退旧数量。用户已明确授权最新来源替换旧数量。未删除页面筛选、导出、汇总或缓存能力。

主线同步包含 #285 的页面重连状态修复与 #287 的订单取消/改单指标独立加载；GEA #364 的独立 GenUI 依赖接线也完整保留。本次未另行修改这些模块。历史调拨口径和分仓范围修复均已核对；取数来源变化按本次明确需求实施，无新增待定位 Bug。GEA 配套兼容测试原先仍拒绝 Workbench 88，已更新允许边界并继续拒绝未声明版本。

本轮完整回归发现并修复新总量覆盖货龄区间的回归：显式选择60–90天或90天以上时，数量和合计只累计所选批次；无区间筛选时采用最新仓库SKU总量。保留原断言，新增独立新旧数量不一致的场景。最终566项Python/SQL回归全通过；其中59项订单/异常回归、10项货龄筛选测试及12项实际数据卡片/筛选合计对账通过。真实GEA筛选查询通过且没有字段裁剪。

验证：128 项 SQL 回归、18 项货龄回归、9 项新来源业务测试、144 项卡片/列表/ETL 数值断言，以及 11 项分仓页面组件回归通过。真实受控网关补货卡片、补货列表、当前订单、货龄卡片查询通过，没有返回字段裁剪。V18 的 170 条语句通过解析；调整后的业务 SELECT 和两张新源表前后内容指纹查询已在实际数据源执行。

V18 保留现有批次校验、原子启用和旧批次保留机制，增加新来源空表、空键、重复键及前后指纹校验。未新增表或权限，未执行生产汇总写入。数据处理人员需在全部明细同步成功后串行运行 V18；插件发布本身不会将旧物化汇总改成新来源。

发布来源为 dsh-plugin-release 1.3.0 本地已安装技能，团队维护仓未登记，核验状态 local_draft。源码修复 [Workbench #288](https://github.com/CleverC2200/dsh-agent-workbench/pull/288)、兼容声明 [GEA #362](https://github.com/CleverC2200/dsh-gea-plugin/pull/362)。实际版本、频道及下载核验完成后补记；正式客户端安装及生产 V18 执行需要分别验收。

合并最新主线后的补充验证：GEA 0.0.264、Workbench 0.1.88、Manage 0.6.3-company.62 原包完成候选三包交付及隔离官方安装/Host接收，证据集合摘要 `676e47d66894780ad6d66f7a129ac62a575d4e4cf7c36fab54c271faf75a3799`。另有8项最终页面回归通过；未启动Native或调用真实DMS业务写入。
