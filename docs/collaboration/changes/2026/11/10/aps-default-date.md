# 默认日期与手选日期

看板默认日历曾直接使用当天，生产源未同步到当天时，日度生产卡片为空。本次默认进入先读取当前权限、当前基地范围内最新有计划及实际产出记录的业务日，再同步日期选择器和看板范围。手选年月周日后严格按选择读取；保存手选模式，且较晚返回的默认日期不能覆盖新选择。智能工作台保留独立的月度日期。

新增轻量受控只读日期查询，使用既有已发布MES字段、命名参数及原权限；保留原数量公式、现有指标SQL、零值与未知值区分。权限或字段拒绝继续显示结构化失败，不更换未发布来源。

回归覆盖默认日期、首次请求范围、手选空日期、手选模式恢复、迟到响应、已有生产和销售判定。六项回归、增量格式与lint、页面构建通过。当前账号真实网关及本地构建页面验证默认值、手选值和库存订单卡片正常；正式发布及原生安装验收另留回执。Workbench准备版本0.1.86。
