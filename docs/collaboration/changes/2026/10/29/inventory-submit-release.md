# 库存单位与补货确认发布

当前订单、占用和缺口按业务单位转换率逐行换算为件，再进行订单与 SKU 汇总；换算率缺失时保留未知，不把袋数直接显示成件。基地、分仓、全链和产销协同采用同一转换规则。

补货确认先显示弹窗，按所选分仓读取，每批 200 行，沿用 20 分钟有效目录缓存。修正分页总数与有效标识范围不一致，缺标识明细单独提示；保留权限错误、取消和不完整输入的阻断。底部勾选项与按钮居中对齐。

产销协同问数上下文包含本期、上月同期及去年同期的指标、期间与来源错误；历史整月值不能冒充月中同期。完整历史月补齐需求计划依赖。

验证：定向 Node 回归 15 项通过；数量换算及订单范围 Python 回归 21 项通过。PR 必要 CI 另按实际记录。源提示词与 Skill 未修改，没有三插件联合启动检查。

验收限制：当前测试环境 SQL 仍返回数据权限拒绝；DMS 独立测试登录成功不代表当前客户端完整暂存流程通过。本版不宣称 DMS 全流程已验收，也不补造缺失历史指标。
