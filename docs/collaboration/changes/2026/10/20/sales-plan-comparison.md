# 销售计划单行版本对比与组织SKU分摊

销售计划的版本对比入口恢复后，现将版本①、版本②选择器放入顶部同一行。列表和内联SKU明细显示两版数量、金额及差异，历史版本缺失保持空值。原独立明细弹窗已按用户要求移除，旧详情动作沿现有内联展开。

同组织多计划可编辑SKU确认总量，按各计划原确认数量占比分摊，保留三位小数和确定性尾差，金额按各计划各自单价计算。调整保存为原有本地草稿，真实审批仍走既有确认与权限校验。

从最新main单独提取版本对比功能，保留主线重复点击纠偏节点时的输入、终态混合分组和未提交页面状态保护。相关39项回归及官方类型检查通过。原本机候选已完成单行布局和十月真实列表只读验收；整合主线候选的托管CI以本PR实际结果为准。未执行正式发布或真实审批写入。

移除的私有弹窗组件及样式由用户“压缩到一行，去掉之前做的那个明细弹窗”明确授权，替代入口由列表内联明细覆盖。共享读取hook和历史来源清单保留。
