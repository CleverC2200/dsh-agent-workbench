# MPS展示精度

按用户截图要求，逐月测算的环比法、占比法和加权数量显示整数，环比链与同期平均占比显示百分比。MPS页面百分比统一显示两位小数，覆盖基础核对、年度环比、销售提报占比、历史比例和下游拆分占比。

只在单元格显示时格式化，计算函数、来源数据和Excel数值不舍入。历史平均环比和三年同比/环比系数仍按原系数表达，不改变已确认业务口径。缺值继续显示为空占位，真实零保留。

浏览器用带小数的真实计算路径验证整数与百分比显示，并直接检查Excel单元格仍是原始数值。开发客户端验收、CI和正式发布身份以对应PR及本轮发行回执为准；本批插件须包含此展示改动，验证后再发布。
