# 按大类 SKU 汇总表无法向下滚动

用户在销售计划的“按大类 / SKU”视图中无法向下查看后续 SKU。汇总区没有参与父级纵向布局的剩余高度分配，内部滚动容器随表格内容增高，随后被工作台外层裁切。

汇总区改为可收缩的纵向布局，筛选和范围说明保留在表格上方，表格滚动区使用剩余高度。上下和左右滚动均在表格内完成，表头随纵向滚动保持可见。沿用既有表格语义、命名区域及键盘焦点入口。

新增 40 SKU 回归先复现滚轮后滚动位置仍为 0，再验证正常和窄窗口能滚到合计、键盘 Home/End 及横向滚动。79 项页面回归、格式、lint、注释及差分空白检查通过。本任务 Mac 开发客户端接入重新构建的 Native 页面，实际滚到合计并查看最右侧确认量和金额通过。只替换本任务开发实例的页面产物，没有修改数量、提交审批或覆盖正式客户端；正式发行另记。

首次远端浏览器回归为108/109，新增滚动用例未通过。使用本机 Chrome 复现后，确认测试在切换视口后的 Home 回顶尚未完成时就发送下一次滚轮。补充到顶断言后再继续滚动，保留原到合计、键盘和横向滚动要求；Chrome 的3项 SKU 回归通过。原失败运行与诊断保留，不跳过检查或修改产品逻辑掩盖测试失败。
