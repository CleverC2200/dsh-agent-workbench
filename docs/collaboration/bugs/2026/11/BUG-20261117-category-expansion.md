# 品类维度仍可展开组织编辑且品类只读

开启品类维度后，组织行仍进入整组 SKU 编辑，品类行却被编辑条件排除。跨客户组织的品类还藏在组织层级下，无法直接按当前组织范围展开品类并拆分修改。

修复后，开启品类维度时组织只显示汇总，直接展示当前组织范围下的品类行。只允许品类行展开，明细只展示该品类 SKU。复用现有确认量拆分和逐计划草稿：按原确认量比例分配，月初与纠偏取整并用尾差分配保持合计；原数量合计为零时平均分配。金额仍按各客户自己的单价计算，原审批权限与业务提交入口保留。关闭开关恢复原组织编辑方式。

原回归先稳定复现组织编辑入口仍存在。新增验证覆盖单客户、跨客户不同单价、切换品类保留其他草稿、省区与大区退回后审批、只读权限；同时保留月计划、达成率、顶部差额、导出和草稿恢复回归。

初始候选为 Workbench 0.1.128、GEA 0.0.307；因并行发行占用版本号，最终使用0.1.129与0.0.308，发布及实际客户端验收见下文。未提交业务审批。本次按用户明确要求关闭品类模式下的组织展开入口，其他旧修复与功能保留。
