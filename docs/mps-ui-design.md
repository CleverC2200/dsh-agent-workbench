# MPS 桌面页面设计

## 适用范围

用于主生产计划七步的 PC 客户端全宽和会话分栏视图。颜色、字号和可见焦点沿用 Workbench 主题。日常阅读顺序是业务标题、筛选及操作、表格和结果。

## 折叠卡片

- 参照需求确认里的「产品明细」。收起时整行可点击，左侧用原生箭头指示展开状态。标题使用正文色，卡片用白底和细边框。保留键盘焦点与原生展开行为。
- 次要明细默认收起。收起时显示标题，按需加数量或异常状态。沿用业务已有的默认展开区和页面恢复状态。
- 展开后复用同一行标题。筛选紧随标题，操作和下载靠右。宽度紧张时在卡片内换行。表格紧接工具栏，取消重复标题。
- 下载使用统一图标和按钮样式，放在对应表格的标题行，无可导出的记录时禁用。计算口径和字段定义收进就近的「口径说明」，页面直接展示影响当前操作的异常、等待状态和数据缺项。
- 表格行内的明细、树形层级和下拉选择使用各自的交互。卡片采用原生 `details` 和 `summary`，复用 [`mps-report-details` 与 `mps-disclosure-toolbar`](../static/mps/source/demand-confirmation.css)。
- 页面说明默认收起，点标题旁的说明按钮在页内展开，核对底稿的下载入口放在说明区。

## 弹窗

- 「关闭」统一放在标题栏右侧，支持 Esc。底部仅显示下载、取消、保存或确认等操作。没有底部操作时，正文延伸到弹窗底部。

## 表格分页

- 分页放在表格底部右侧，位于横向滚动区之外。共用 [表格分页](../static/mps/source/report-page.js)，从左到右显示每页条数选择、页码与记录数、上一页和下一页。
- 每页条数只在选择框显示，页脚记录数按当前筛选计算。来源说明及异常按需要放在数据源或业务状态区，页脚只留分页信息。

## 页头操作

- MPS 从步骤导航开始。分栏时会话控件放在会话区顶部，全宽且空间充足时与步骤导航共用一行。
- 版本下拉跟随左侧月份，选项显示版本名。版本名称中的固定「X月滚动评估」前缀在页头省略。
- 「刷新」仅更新当前步骤的业务数据。第 2 步从这里重新读取发货计算快照。第 6、7 步显示最近一次评估结果，运行评估需使用评估按钮。
- 产品和主数据的原始记录在对应表格的「查看源表」中核对。连接失败时，客户端显示「重新连接页面能力」。
- 本月预估发货、需求加工与收敛、约束与配置的批量「调整」放在页头操作区最右侧。编辑时同处显示「保存调整」和「取消」，需要填写原因时同时显示原因选择。

## 表格工具栏与导出

- 统计范围、筛选与操作放在对应表格的标题行。已由评估确定的期间直接显示日期范围。
- 可选月份统一显示为 `YYYY-MM`，共用[中文月份选择器](../static/mps/source/month-picker.js)和 Workbench 主题色。
- 「下载目标库存」的当前筛选表核对单品周转天数与目标库存，三个月库存汇总按月份和基地核对小计与待补数，目标源记录核对数仓原值及周转天数采用情况。
- 同一业务报表只留一个下载入口。Excel 按业务结果、源明细和实际异常命名工作表，保留筛选和版本口径。公式说明放在页面的「口径说明」中，导出只保留业务结果及核对所需字段。
- 正文只显示业务值和影响读数或操作的状态。来源表、配置版本、统计口径和推导说明按需查看。筛选项已显示的期间只保留一处，缺项提示标在受影响的字段或行。
