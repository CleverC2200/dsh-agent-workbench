## 保留的业务与授权条件

本地直连只用于已授权的本机核对，凭据留在受保护的忽略目录，不进入前端、SQL 配置、日志、截图或安装包。GEA 拒绝后不回退数据库直连，不通过其他未发布表补取受限字段。

原教程中的经销商核对例子有明确范围：该批有效小计排除负数，不能推广为所有负数转零或删除。原确认库存和动销单位为箱、库存金额为元；支撑天数使用同一批在仓、在途和近30日动销均有效的记录，分母为零保持未知，不混用两批事实。该例的原要求和公式见[固定业务章节](https://github.com/CleverC2200/dsh-agent-workbench/blob/e3d9b5b3d65947005cd6bbfc255c8d3379df086e/docs/html-plugin-development-guide.md#L224)，当前经销商实现与来源见 [SOURCE](../business/inventory-dealer/SOURCE.md)。业务口径变化需按对应业务要求核对，不由本次文档路由整理裁决。

资源、Consumer、身份、返回列权限、分页和截断必须在目标环境验证。取消、切用户、切 Session、超时与迟到结果不得沿用旧请求的授权。源码接线、页面预览、安装和真实业务验收分别记录，原失败与未完成项不因入口整理关闭。

## 原交付要求的逐项核对

以下保留原交付要求，未由本轮整理补写通过结论；按实际任务输入逐项核对。

- [ ] 页面与字段清单，旧版布局基线。
- [ ] 表结构、事实粒度、单位、日期及关联关系说明。
- [ ] 每个 Agent 独立 SQL 配置，参数与返回列合同完整。
- [ ] 字段缺口一行一个，已补字段从旧缺口说明同步更新。
- [ ] 默认10行服务端分页，汇总不依赖当前页。
- [ ] NULL、零、负数、异常、缺权限分别处理。
- [ ] 快照时间与有效范围清楚，模型上下文保留相同口径。
- [ ] 页面、资源、Consumer与能力声明一致。
- [ ] 取消、切用户、切Session和迟到结果处理正确。
- [ ] 有独立对账、相关测试、实际耗时和最终页面截图。
- [ ] 作者源、SQL配置与构建产物一致，包内无凭据和开发路径。
- [ ] 直连、GEA、安装与发布的完成状态分别记录。
