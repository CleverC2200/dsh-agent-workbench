# 全链库存卡片与日期筛选修复

首页卡片适配存在三处漏接：分仓周转绑定了补货汇总，但首页并未请求该汇总；分层货龄直接写为空；当前订单卡片的两行缺货量直接写为空。

- 分仓周转复用 `replenishment.summary.historical_turnover_days`，按同仓库 SKU 的可用库存与近30日日均正向发货汇总计算。用该查询替换首页未消费的独立分仓发货汇总，首页来源查询仍为9项，不拉明细。
- 基地货龄在已有 `health.summary` 中按 `warehouse_type='基地仓'` 计算 `base_max_age`；分仓使用已有独立库存快照汇总的 `max_age`。这两项和主卡片保持最大库龄口径，解释置于原有悬停说明，不能作为平均货龄使用。
- 当前订单主值仍是基地最新库存快照的未备单量。下方两行接入已有工厂、分仓订单履约汇总的 `shortage`，明确标为“基地本月缺货量”“分仓本月缺货量”，不把月累计缺货冒充当前订单阶段缺货。
- 日期框保留 ISO 查询值、原生日期选择和键盘能力，显示固定为中文年月日；采用36px控件高度、日历图标、边框与焦点状态。编辑筛选不立即查询，提交后读取新日期。

正式 GEA 的全链 Consumer 只读验证与直连逐字段一致，未裁列：基地最大库龄405天，分仓360天，分仓周转11.16202821天；本月工厂缺货241897箱、分仓缺货16163箱。五项查询网关耗时约0.98—2.21秒，该耗时不代表整页加载时间。

当前分仓待发订单阶段及快照仍缺等价来源；本次接入的本月履约量不替代它们。缺失同步字段继续维护在[缺失字段清单](agent-missing-fields.md)。
