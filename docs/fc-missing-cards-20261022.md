# 分仓卡片缺值核对（2026-10-22）

本机已安装 Workbench 0.1.24，尚未包含草稿 PR #79 的当前未备单订单接线。

| 页面指标 | 旧值原因 | 修复及来源 |
| --- | --- | --- |
| 超龄库存量 | 批次表改版后适配层固定返回 NULL | 沿原分仓 BRANCH_RULESET，逐批次累计货龄 >=60 天的正 live_qty |
| 滞库风险量 | 页面固定为空 | 沿原规则逐批次累计货龄 >=90 天的正 live_qty，接入现有 health.summary |
| 当前订单 | 旧页面用期间订单存在与否强制显示 0 | 草稿已改为当前未备单 adjust_order_qty；按订单自身 qtyallocated、库存池 SKU 的 available_qty 三层算缺口 |

风险量使用 agents_scm_inventory_sku_data_d 的 month_date、prod_date、live_qty；仓库与 SKU 分组用 warehouseid、material_code。缺日期、不合法货龄、非正库存不计入风险量。不用 SKU 最大货龄判断整个 SKU 的库存，也不下载全部批次到页面求和。原库存范围、筛选和布局保持。

65 项 SQL 测试通过，其中新场景实际执行交付 health.summary，覆盖 59/60/89/90 天、负库存、缺生产日期和未来生产日期。新场景修复前返回 NULL，修复后超龄/滞库分别为 90/40。

本次快照按当前页面的仓库编码事实集：现库存 5,253,232.1 箱、最大货龄 1,029 天、超龄库存 209,791.5 箱、滞库风险 139,903.5 箱。现库存与最大货龄和用户截图一致。货龄两个风险量经统一 GEA SQL 的 queryConfigured 路径验证，与直连结果一致，无返回字段拒绝。

当前未备单的直连核验值为需求 51,242 箱、缺口 15,039.8 箱；正式 GEA 对订单执行表仍返回 ROW_SCOPE_DENIED。它们不是正式客户端已成功加载的值。查询失败保留未知，不使用直连回退、不再固定为 0。

真实直连预览已验证卡片接线、390px 自适应和页面无脚本错误。未把预览当作正式客户端订单权限验证。此轮未安装、未合并、未发版。
