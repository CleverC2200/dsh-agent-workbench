# 五个 Agent 顶部布局统一

全链、分仓、基地、经销商及产销协同复用 `BusinessToolbar`：主工具栏最小高度56px，左右内边距16px，控件高度36px，控件间距8px。对象或范围放左侧，日期与刷新放右侧；窄屏自动换行，业务步骤和页签横向滚动。

| Agent      | 左侧                    | 右侧                 | 独立导航行                     |
| ---------- | ----------------------- | -------------------- | ------------------------------ |
| 分仓库存   | 全部分仓、补货周期      | 日期、刷新           | 五步运营导航                   |
| 全链库存   | 含渠道开关              | 日期、查询/刷新      | 原业务页签保留在内容区         |
| 基地库存   | 基地选择                | 日报、刷新           | 原业务页签保留在内容区         |
| 经销商库存 | 客户选择                | 日期、查询/刷新      | 客户库存/客户订单              |
| 产销协同   | 智能工作台/产销协同看板 | 原统计日期选择、刷新 | 原业务视角及统计粒度保留在看板 |

经销商日期刷新保留已选客户，未提交的客户草稿不影响日期刷新。产销协同复用原日期选择、月份状态及刷新通道；嵌入模式将日期移动到顶部，独立原型仍保留原位置。日期弹出菜单按工具栏边界定位，窄屏不超出可视区。

共用组件兼容库存页面的 `ui-*` 主题令牌及产销协同的 `workbench-*` 令牌，保留客户端深浅色能力与业务状态色。此次只调整呈现和筛选入口位置，不改 SQL、业务指标、身份通道或分页规则。

五个 Agent 的宿主名称标题栏已移除，业务页面从顶端开始。分屏和会话模式下，会话操作栏保留在 AI 区顶部；业务最大化时移至底部，避免遮挡筛选工具栏。其他业务页面的宿主标题栏保持原布局。
