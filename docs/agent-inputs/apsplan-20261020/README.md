## 接入时必须核对

1. 附件使用 `cube_new` 和 `gea_kb` 工具约定；实际可执行工具以 Host 运行时登记及当前身份权限为准。现有 APS HTML 的声明为 `governed-sql-read`，不能仅复制工具名称就声称能力可用，也不能替换现有统一身份与 SQL 通道。
2. 系统提示词禁止猜测 Cube 成员；周报 Skill 在模型检查失败时允许一次猜测候选查询，二者冲突。运行版本应采用成功元数据中实际返回的成员，禁止猜测回退；原始附件在此保留供审查。
3. 订单分析附件以“件”为单位，当前插件已确认 1 件 = 1 箱、页面统一展示箱。接入时保留该确认及单位映射，确保卡片、列表和报告口径一致。
4. 用户此前要求缺失业务数值按 0 参与页面计算；附件保留缺失为 null 的分析约定。接入时区分已成功查询的业务空值、权限拒绝、查询失败与零分母，说明使用的补零口径，不能把失败伪装成实际零。
5. 涉及受控 SQL 的提示词、模板或脚本修改，先遵循项目约定的 `gea-governed-sql` 规范：已发布资源与字段、只读查询、命名参数、返回权限和结构化错误处理。附件中的表名、字段名或示例不授予查询权限。
